## ① ゲームの前提・概要

```
【このデモの前提】
- ジャンル：2Dブロック崩し（縦画面・ポートレート）
- 画面解像度：1080×1920（縦長）。UnityのGame Viewを 1080×1920 に設定し、Canvas／UIもこの解像度を基準に作る。
- 画面遷移：Title → InGame → Result(GameOver) → Title（1シーンでパネル差し替え）

【ゲームの概要】
一般的なブロック崩しに、次の特徴を加えたオリジナル。
- ブロックは赤・青・緑・黄・シルバーの5種類。
  赤〜黄は1発で割れる。シルバーは硬い金属ブロックで、複数回当てないと割れない。
- ブロックを崩すと、同じ色のパワーアップアイテムが一定確率で落下し、パドルで取るとパワーアップする。
- 一定時間ごとに画面上部から敵が出現。敵は「動くブロック」扱いで、ボールが当たると跳ね返る。
- 場のボールが全て画面下部に落ちると1機消滅（敵はパドルと衝突せず、1機消滅の原因にはならない）。
- ブロックを全て壊すとステージクリア。複数の固定ステージを順番に進み、最終ステージクリアでゲームクリア。
```

## ③ 操作・パワーアップアイテム

```
【操作】
- 左右キーでパドルを移動（画面外へは出られない）
- スペースキー：待機中のボールを発射する

【ボールの待機・発射（ステージ開始時・ミス後の再開時）】
- ボールはパドルに接触させず、パドルの少し上に浮かせた状態でセットする
  （接触させると物理的に押し合い、ボールが小刻みに震えてしまうため）。
- 待機中はパドルの左右移動に合わせて、ボールも一緒に左右へ動く。
- スペースキーで、ボールを斜め上方向（真上は除く・左右ランダム）へ発射する。

【パワーアップアイテム】
1. ダブルボール（赤ブロックから出現）：ボールが倍に増える
2. 貫通ボール（青ブロックから出現）：一定時間、ボールがブロック・敵に当たっても跳ね返らず、
   貫通して直進しながら連続で破壊する（敵へのダメージは通常と同じ。効果は時間切れ、またはミスで終了＝早い方）
3. ビッグボール（緑ブロックから出現）：ボールが倍の大きさになり、ブロック・敵へのダメージも2倍
4. ロングパドル（黄ブロックから出現）：パドルの長さが1.5倍（複数取っても1.5倍より長くはならない）

※シルバー（金属）ブロックはアイテムを落とさない（パワーアップアイテムのドロップ対象外）。
```

## ④ 敵

```
【敵】
- 3種類（Enemy1〜3）。各2枚の画像を一定間隔で差し替えるだけの簡易アニメ
  （Animator / Animation 機能は使わない）
- HP：Enemy1=1、Enemy2=2、Enemy3=4（ビッグボール命中時はダメージ2倍）
- 画面上部から一定間隔で出現し、ふわふわ移動しながら徐々に下方向へ進む
- ブロックとは重ならないように移動する
- パドルとは衝突しない。ボールで倒さない限り下へ進み、画面下のボール消滅エリアに触れると敵も消える（スコア加算もSEもなし）
```

## ⑤ ステージのブロック配置

```
【ステージのブロック配置】
各ステージのブロックは「文字マップ」で指定する。1文字＝ブロック1個で、左上から格子状に並べる。
- R=赤、B=青、G=緑、Y=黄、S=シルバー、.（ドット）＝空白（ブロックを置かない）
- 上の行から下へ、左の文字から右へ並ぶ。マップの見た目どおりに配置する。
- ブロック同士の間隔や全体の余白は、画面に収まるようAIが調整してよい。
- 具体的なマップは次のブロック「ステージ構成」で送ります。
```

## ⑦ UI・数値の初期値

```
【UI】
- 背景に background 画像を配置
- 画面左下：残機をパドルのミニ画像として横並びで表示（初期残機3）
- パドルは画面下部、残機表示と被らない高さに配置
- 画面上部：左から「ステージ数」「スコア」「ハイスコア」を TextMeshProUGUI で表示

【数値の初期値（AIが調整してよい）】
- スコア：ブロック=100 / 敵撃破=Enemy1:200・Enemy2:400・Enemy3:800
- アイテム落下確率：ブロック1個あたり 25%（シルバーブロックはアイテムを落とさない＝対象外）
- シルバーブロックのHP：4（通常ボール4発／ビッグボール2発で破壊）
- パワーアップの持続：1機消滅（ミス）でリセット
- ハイスコアは次回も保持する（PlayerPrefs 等）
```

## ⑧ 効果音（SE）

```
【効果音（SE）】
SEは Demo/BrickBreaker/SE に配置済み（ogg）。
BGMは今回は無し。

用途ごとの枠と、鳴らす場面：
- block.ogg > 通常ブロック（赤・青・緑・黄）を崩した時
- silverBlock.ogg > シルバー（金属）ブロックにボールが当たった時（硬くて弾く音）
- paddle.ogg > ボールがパドルに当たって跳ね返った時
- enemyDamage.ogg > 敵にボールが当たってダメージを与えた時／敵を撃破して消滅させた時（敵消滅も同じ enemyDamage.ogg を流用。敵消滅専用SEは用意していない）
- itemGet.ogg > 落下アイテムをパドルで取得した時
- button.ogg > タイトルなどで決定ボタンを押した時
- textOpen.ogg > ステージ開始／終了時に「ステージ2」などのステージ表示テキストを出す時
- playerDeath.ogg > プレイヤーが1機消滅（ミス）した時

【素材の移動】実装時は、これらのSEを Demo フォルダのままにせず、Unityの Assets/Project/Audio/BrickBreaker/ フォルダ（無ければ作成）へ移動してから使う。
```

## ⑨ 素材

```
【素材（画像）】Demo/BrickBreaker/Images に配置済み（宇宙テーマのドット絵）。

すべて低解像度のドット絵なので、Unityでの取り込み設定（各画像の Inspector → Texture Importer）を次のようにして、拡大してもにじまない・ぼやけないようにする：
- Texture Type：Sprite (2D and UI)
- Filter Mode：Point (no filter) … ドット絵のにじみ防止（最重要）
- Compression：None … 圧縮による色劣化・ノイズを防ぐ
- Generate Mip Maps：オフ（チェックを外す）
- Sprite Mode：Single（各画像は1枚絵として扱う）
- 設定を変えたら必ず Apply を押す。

【各画像の一覧】
- background.png（256×512）> 背景（宇宙・銀河、縦長）
- ball.png（12×12）> ボール
- paddle.png（32×8）> パドル（左下の残機ミニ表示にも流用）
- block_red / blue / green / yellow / silver.png（各16×8）> 各色ブロック
- item_red / blue / green / yellow / silver.png（各16×8）> 各色の落下パワーアップアイテム
  （※item_silver は現状未使用：シルバーブロックはアイテムを落とさないため）
- enemy1_0 / enemy1_1 / enemy2_0 / enemy2_1 / enemy3_0 / enemy3_1.png（各16×16）
  > 敵3種 × 各2フレーム（パラパラ差し替えアニメ用）

【素材の移動】実装時は、これらの画像を Demo フォルダのままにせず、Unityの Assets/Project/Images/BrickBreaker/ フォルダ（無ければ作成）へ移動してから使う。
```

## ⑩ フォント

```
【フォント】Demo/BrickBreaker/Font に NotoSansJP-Black.ttf を配置済み（太めのゴシック体。視認性が高く、スコアやステージ表示などの数字・日本語に適している）。
- この .ttf から TMP_FontAsset を作成し、ゲーム内のすべての TextMeshProUGUI
  （ステージ数・スコア・ハイスコア、ステージ表示テキストなど）に使用する。
- 文字がくっきり表示されるよう、必要に応じて TMP_FontAsset の生成設定（サンプリング解像度・パディング等）を調整する。

【素材の移動】実装時は、このフォントを Demo フォルダのままにせず、Unityの Assets/Project/Fonts/ フォルダ（無ければ作成）へ移動してから TMP_FontAsset を作成する。
```
