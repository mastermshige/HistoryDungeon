## 縄文時代（+3問）

### 解説ページの修正案（2ページ → 3ページ）

1. （そのまま）縄文時代は、約1万年前ごろに始まったとされる時代じゃ。
2. （そのまま）人々は狩りや漁、木の実の採集で暮らし、縄目の模様がついた縄文土器を使ったのじゃ。
3. **（新規）** 地面を掘りくぼめた竪穴住居に住み、食べ物のかすを捨てた貝塚や、まじないに使った土偶が残っておるぞ。

年表は変更なし。

### 追加する問題

**J4** キャラ: 貝がらバット
- 問題: 縄文時代の人々が、食べ物の残りかすや貝がらなどを捨てた場所の跡で、当時の暮らしを知る手がかりになるものは？
- 正解: **貝塚**
- 誤り: 古墳 / 環濠 / 銅鐸
- 解説: 貝塚には貝がらのほか、魚や動物の骨、土器なども残っておるのじゃ。縄文人が何を食べていたかが分かるぞ。

**J5** キャラ: 土偶ゴースト
- 問題: 縄文時代に、女性をかたどってつくられ、豊かな実りや安産などをいのるまじないに使われたと考えられる土製品は？
- 正解: **土偶**
- 誤り: 埴輪 / 銅鐸 / 銅鏡
- 解説: 土偶は縄文時代の土製品じゃ。埴輪は古墳時代、銅鐸や銅鏡は弥生時代以降の青銅器じゃから、混ぜてはならんぞ。

**J6** キャラ: 竪穴スパイダー
- 問題: 縄文時代の人々が暮らした、地面を掘りくぼめて柱を立て、屋根をかけた住居は？
- 正解: **竪穴住居**
- 誤り: 高床倉庫 / 寝殿造 / 書院造
- 解説: 縄文時代の人々は竪穴住居に住んでおったのじゃ。高床倉庫は弥生時代、寝殿造は平安時代、書院造は室町時代の建物じゃぞ。

## 弥生時代（+3問）

### 解説ページの修正案（3ページ → 4ページ）

1. （そのまま）弥生時代は、大陸から稲作と金属器（青銅器・鉄器）が伝わり、米づくりが広まった時代じゃ。
2. （そのまま）米づくりで貧富の差が生まれ、ムラどうしの争いから、小さな国（クニ）ができていったのじゃ。
3. **（新規）** 稲は高床倉庫にたくわえ、豊作をいのる祭りには青銅の銅鐸が使われた。静岡県の登呂遺跡には、水田の跡が残っておる。
4. （そのまま・最後へ移動）中国の歴史書には、倭（日本）の国々の様子が書かれておる。57年・107年・239年の3つの年号は特に大事じゃ！

年表は変更なし。

### 追加する問題

**Y5** キャラ: 登呂スライム
- 問題: 静岡県にある、弥生時代の水田や住居の跡が見つかった遺跡はどれじゃ？
- 正解: **登呂遺跡**
- 誤り: 三内丸山遺跡 / 板付遺跡 / 岩宿遺跡
- 解説: 静岡県の登呂遺跡は、弥生時代の水田や住居の跡が見つかった遺跡じゃ。板付遺跡は福岡県、三内丸山遺跡は青森県にあるぞ。

**Y6** キャラ: 高床ゴブリン
- 問題: 弥生時代に、収穫した稲をたくわえるために建てられた、ねずみや湿気を防ぐ工夫のある倉庫は？
- 正解: **高床倉庫**
- 誤り: 竪穴住居 / 貝塚 / 環濠
- 解説: 高床倉庫は、床を高くして湿気やねずみから稲を守る倉庫じゃ。米づくりが広まった弥生時代の代表的な建物じゃぞ。

**Y7** キャラ: 銅鐸ゴーレム
- 問題: 弥生時代に、豊作をいのる祭りなどで使われたと考えられる、青銅でつくられた釣り鐘の形の道具は？
- 正解: **銅鐸**
- 誤り: 土偶 / 埴輪 / 石包丁
- 解説: 銅鐸は、祭りの道具として使われた青銅器じゃ。石包丁は稲の穂をつみ取る道具、土偶は縄文時代、埴輪は古墳時代のものじゃぞ。

## 古墳時代（+3問）

### 解説ページの修正案（3ページ → 4ページ）

1. （そのまま）古墳時代は、3世紀後半ごろから、各地に大きな古墳（お墓）がつくられた時代じゃ。
2. （そのまま）近畿地方の有力者たちが集まったヤマト政権（大和政権）が、大王を中心に各地の豪族をまとめていったのじゃ。
3. **（新規）** 大阪府堺市の大仙古墳のような前方後円墳には、埴輪が並べられた。朝鮮半島からは渡来人が来て、進んだ技術を伝えたのじゃ。
4. （そのまま・最後へ移動）ヤマト政権は朝鮮半島にも進出し、中国の宋にも使いを送った。391年・421年・478年・527年をおぼえよう！

年表は変更なし。

### 追加する問題

**K5** キャラ: 古墳ドラゴン
- 問題: 大阪府堺市にある、面積が日本最大の前方後円墳で、仁徳天皇の墓とされる古墳は？
- 正解: **大仙古墳**
- 誤り: 箸墓古墳 / 稲荷山古墳 / 江田船山古墳
- 解説: 大阪府堺市の大仙古墳（仁徳天皇陵古墳）は、面積が日本最大の前方後円墳じゃ。箸墓古墳は奈良県にある、古い時期の大きな古墳じゃぞ。

**K6** キャラ: 埴輪ゴースト
- 問題: 古墳の頂上や周りに並べられた、人・馬・家などの形をした素焼きの焼き物は？
- 正解: **埴輪**
- 誤り: 土偶 / 銅鐸 / 須恵器
- 解説: 埴輪は古墳のまわりに並べられた素焼きの焼き物じゃ。土偶は縄文時代、銅鐸は弥生時代のものじゃぞ。

**K7** キャラ: 渡来スケルトン
- 問題: 5世紀ごろ、朝鮮半島から日本に移り住み、機織り・土木・須恵器づくり・漢字の使い方などの進んだ技術や知識を伝えた人々は？
- 正解: **渡来人**
- 誤り: 防人 / 国造 / 遣唐使
- 解説: 渡来人は、朝鮮半島や中国から日本に移り住んだ人々じゃ。ヤマト政権のもとで、進んだ技術や知識を伝えて活やくしたぞ。

**A6** キャラ: 冠位ゴブリン

- 解説: 694年、持統天皇が日本で初めての本格的な都、藤原京に都を移したのじゃ。710年の平城京の前の都じゃぞ。

### 追加する問題

**N6** キャラ: 書紀スケルトン
- 問題: 舎人親王らによって、国が編さんした歴史書『日本書紀』が完成したのは、何年じゃ？
- 正解: **720年**
- 誤り: 712年 / 723年 / 743年
- 解説: 720年に『日本書紀』が完成したのじゃ。712年の『古事記』は物語のような書き方、『日本書紀』は漢文で年を追って書かれておるぞ。

**N7** キャラ: 国分寺ゴーレム
- 問題: 聖武天皇が、病気や災いをしずめるため、国ごとに国分寺・国分尼寺を建てるよう命じたのは、何年じゃ？
- 正解: **741年**
- 誤り: 723年 / 743年 / 752年
- 解説: 741年、聖武天皇は国分寺建立の詔を出し、全国に国分寺・国分尼寺を建てさせたのじゃ。743年には大仏をつくる詔も出されたぞ。

**N8** キャラ: 鑑真ゴースト
- 問題: 唐の僧の鑑真が、何度も渡航に失敗しながら、日本にたどり着いたのは、何年じゃ？
- 正解: **753年**
- 誤り: 743年 / 752年 / 794年
- 解説: 鑑真は失明しながらも、753年に日本にたどり着き、正しい仏教のきまりを伝えたのじゃ。のちに唐招提寺を開いたぞ。

## 平安時代（+3問）

### 解説ページの修正案（2・3ページ）

2. 〔修正〕前半は藤原氏が摂政・関白として政治を動かし、紫式部の『源氏物語』などの国風文化が栄えた。後半は上皇が院政で力を持ち、やがて武士が力をのばしたのじゃ。
3. 〔修正〕平清盛が太政大臣になるまでの流れをおさえよう！ 794年・804年・894年・1016年・1086年・1156年・1159年・1167年が大事じゃ！

年表は変更なし（6項目のまま。804年・1016年は解説ページと問題で扱います）。

### 追加する問題

**H7** キャラ: 遣唐スライム
- 問題: 最澄と空海が、遣唐使とともに唐にわたって仏教を学んだのは、何年じゃ？
- 正解: **804年**
- 誤り: 794年 / 894年 / 1016年
- 解説: 804年、最澄と空海は遣唐使の船で唐にわたったのじゃ。帰国後、最澄は天台宗、空海は真言宗を開いたぞ。

**H8** キャラ: 摂政ゴブリン
- 問題: 藤原道長が、幼い後一条天皇の摂政となり、藤原氏の力が最も強まったのは、何年じゃ？
- 正解: **1016年**
- 誤り: 894年 / 1086年 / 1156年
- 解説: 1016年、藤原道長は後一条天皇の摂政となったのじゃ。娘を次々と天皇のきさきにして、政治の力をにぎったぞ。

**H9** キャラ: 源氏ゴースト
- 問題: 藤原道長の娘の彰子に仕え、長編小説『源氏物語』を書いた人物は？
- 正解: **紫式部**
- 誤り: 清少納言 / 紀貫之 / 菅原道真
- 解説: 紫式部は『源氏物語』の作者じゃ。清少納言は随筆『枕草子』、紀貫之は『土佐日記』を書いたぞ。
