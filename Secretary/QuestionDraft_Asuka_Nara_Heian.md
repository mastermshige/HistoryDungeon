## 飛鳥時代（問題 5問）

### 教室の解説（黒板・3ページ）

1. 飛鳥時代は、聖徳太子（厩戸皇子）が推古天皇を助けて、天皇を中心とする国づくりを始めた時代じゃ。
2. 冠位十二階（603年）や十七条の憲法（604年）で役人の心がまえを整え、隋にも使いを送ったのじゃ。
3. その後、大化の改新や壬申の乱を経て、律令にもとづく国のしくみが整っていく。607年・645年・663年・672年・701年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 604年 | 十七条の憲法が定められる |
| 607年 | 小野妹子らが遣隋使として送られる |
| 645年 | 乙巳の変（大化の改新の始まり） |
| 663年 | 白村江の戦い |
| 672年 | 壬申の乱 |
| 701年 | 大宝律令が完成する |

### ダンジョンの問題

**A1** キャラ: 遣隋使ゴブリン
- 問題: 聖徳太子が推古天皇の時代に、小野妹子らを遣隋使として隋に送ったのは、何年じゃ？
- 正解: **607年**
- 誤り: 645年 / 663年 / 701年
- 解説: 607年、小野妹子らが遣隋使として隋に送られたのじゃ。隋の皇帝に対等な立場の国書を出したことでも知られておるぞ。

**A2** キャラ: 入鹿ゴースト
- 問題: 中大兄皇子と中臣鎌足らが蘇我入鹿を倒した乙巳の変が起こったのは、何年じゃ？
- 正解: **645年**
- 誤り: 607年 / 672年 / 701年
- 解説: 645年、中大兄皇子と中臣鎌足らが蘇我入鹿を倒したのじゃ。これをきっかけに大化の改新が始まったぞ。

**A3** キャラ: 白村江スケルトン
- 問題: 百済を助けるために朝鮮半島へ出兵した倭の軍が、唐・新羅の連合軍に大敗した白村江の戦いは、何年じゃ？
- 正解: **663年**
- 誤り: 607年 / 645年 / 672年
- 解説: 663年、倭は百済の復興を助けるために出兵したが、白村江で唐・新羅の連合軍に大敗したのじゃ。

**A4** キャラ: 大海人スライム
- 問題: 天智天皇の死後、大海人皇子と大友皇子が皇位をめぐって争った壬申の乱は、何年じゃ？
- 正解: **672年**
- 誤り: 645年 / 663年 / 701年
- 解説: 672年、大海人皇子が大友皇子に勝ち、のちに天武天皇として即位したのじゃ。これが壬申の乱じゃ。

**A5** キャラ: 律令ゴーレム
- 問題: 刑部親王や藤原不比等らによって、唐の律令を手本にした大宝律令が完成したのは、何年じゃ？
- 正解: **701年**
- 誤り: 645年 / 672年 / 710年
- 解説: 701年、文武天皇の時代に大宝律令が完成し、律令にもとづく政治のしくみが整ったのじゃ。

## 奈良時代（問題 5問）

### 教室の解説（黒板・3ページ）

1. 奈良時代は、710年に都が平城京に移されて始まった時代じゃ。律令にもとづく政治が進んだのじゃ。
2. 田んぼを増やすために土地の制度が変わり、貴族や寺社が私有地（荘園）を広げていったぞ。
3. 聖武天皇は仏教の力で国を治めようと、国分寺と大仏をつくった。710年・712年・723年・743年・752年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 710年 | 平城京に都を移す |
| 712年 | 『古事記』が完成する |
| 720年 | 『日本書紀』が完成する |
| 723年 | 三世一身法が出される |
| 743年 | 墾田永年私財法が出される |
| 752年 | 東大寺の大仏の開眼供養 |

### ダンジョンの問題

**N1** キャラ: 平城京ゴーレム
- 問題: 元明天皇が、藤原京から平城京へ都を移したのは、何年じゃ？
- 正解: **710年**
- 誤り: 701年 / 712年 / 794年
- 解説: 710年、元明天皇が唐の長安を手本にした平城京に都を移したのじゃ。ここから奈良時代が始まるぞ。

**N2** キャラ: 稗田阿礼ゴースト
- 問題: 稗田阿礼が暗記した神話や伝承を、太安万侶が書きとめた『古事記』が完成したのは、何年じゃ？
- 正解: **712年**
- 誤り: 710年 / 720年 / 794年
- 解説: 712年、『古事記』が完成したのじゃ。720年に完成した『日本書紀』とまちがえぬようにな。

**N3** キャラ: 開墾スライム
- 問題: 新しく開墾した土地を、本人・子・孫の3代まで私有してよいとした三世一身法が出されたのは、何年じゃ？
- 正解: **723年**
- 誤り: 710年 / 743年 / 752年
- 解説: 723年、田を増やすために三世一身法が出されたのじゃ。743年の墾田永年私財法では、開墾した土地をずっと私有できるようになったぞ。

**N4** キャラ: 荘園ゴブリン
- 問題: 開墾した土地を永久に私有してよいとした墾田永年私財法が出されたのは、何年じゃ？
- 正解: **743年**
- 誤り: 710年 / 723年 / 794年
- 解説: 743年、墾田永年私財法が出され、開墾した土地の私有が認められたのじゃ。これが荘園が広がるきっかけになったぞ。

**N5** キャラ: 大仏ナイト
- 問題: 聖武天皇の命でつくられた東大寺の大仏の開眼供養が行われたのは、何年じゃ？
- 正解: **752年**
- 誤り: 710年 / 723年 / 743年
- 解説: 752年、東大寺の大仏の開眼供養が行われたのじゃ。大仏をつくる詔が出されたのは743年じゃぞ。

## 平安時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 平安時代は、794年に桓武天皇が都を平安京に移して始まった時代じゃ。
2. 前半は藤原氏が摂政・関白として政治を動かし、後半は上皇が院政で力を持ち、やがて武士が力をのばしたのじゃ。
3. 平清盛が太政大臣になるまでの流れをおさえよう！ 794年・894年・1086年・1156年・1159年・1167年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 794年 | 平安京に都を移す |
| 894年 | 遣唐使が停止される |
| 1086年 | 白河上皇が院政を始める |
| 1156年 | 保元の乱 |
| 1159年 | 平治の乱 |
| 1167年 | 平清盛が太政大臣になる |

### ダンジョンの問題

**H1** キャラ: 桓武ゴースト
- 問題: 桓武天皇が、長岡京から平安京へ都を移したのは、何年じゃ？
- 正解: **794年**
- 誤り: 710年 / 784年 / 894年
- 解説: 794年、桓武天皇が平安京に都を移したのじゃ。その10年前の784年には、長岡京に都を移しておったぞ。

**H2** キャラ: 道真ゴースト
- 問題: 菅原道真の意見により、遣唐使の派遣が停止されたのは、何年じゃ？
- 正解: **894年**
- 誤り: 794年 / 1086年 / 1167年
- 解説: 894年、菅原道真の意見により遣唐使の派遣が停止されたのじゃ。唐が衰え、航海も危険だったからじゃ。

**H3** キャラ: 院政スケルトン
- 問題: 白河天皇が位をゆずって上皇となり、院政を始めたのは、何年じゃ？
- 正解: **1086年**
- 誤り: 894年 / 1156年 / 1167年
- 解説: 1086年、白河天皇が位をゆずって上皇となり、院政を始めたのじゃ。天皇の位をしりぞいた上皇が政治を動かす仕組みじゃ。

**H4** キャラ: 保元ゴブリン
- 問題: 後白河天皇方と崇徳上皇方が争い、平清盛や源義朝が後白河天皇方についた保元の乱は、何年じゃ？
- 正解: **1156年**
- 誤り: 1086年 / 1159年 / 1167年
- 解説: 1156年、皇室や貴族の争いに武士が動員される保元の乱が起こり、後白河天皇方が勝ったのじゃ。武士の力が政治を動かし始めたぞ。

**H5** キャラ: 平治ゴーレム
- 問題: 源義朝が兵をあげたが、平清盛に敗れた平治の乱は、何年じゃ？
- 正解: **1159年**
- 誤り: 1086年 / 1156年 / 1167年
- 解説: 1159年、平治の乱で源義朝が平清盛に敗れたのじゃ。これで平氏が武士の中で大きな力を持つようになったぞ。

**H6** キャラ: 清盛ナイト
- 問題: 平清盛が、武士として初めて太政大臣になったのは、何年じゃ？
- 正解: **1167年**
- 誤り: 1156年 / 1159年 / 1185年
- 解説: 1167年、平清盛が武士として初めて太政大臣になったのじゃ。娘を天皇の后にして、政治の実権をにぎったぞ。
