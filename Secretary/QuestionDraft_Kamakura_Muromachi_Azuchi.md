## 鎌倉時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 鎌倉時代は、源頼朝が鎌倉に幕府を開き、武士が政治の中心になった時代じゃ。
2. 将軍と御家人は、土地をあたえる「御恩」と、戦などで働く「奉公」でむすばれていた。頼朝の死後は、北条氏が執権として政治を動かしたのじゃ。
3. 承久の乱から元寇、幕府の滅亡までの流れをおさえよう！ 1185年・1192年・1221年・1232年・1274年・1333年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1185年 | 守護・地頭が置かれる |
| 1192年 | 源頼朝が征夷大将軍になる |
| 1221年 | 承久の乱 |
| 1232年 | 御成敗式目が定められる |
| 1274・1281年 | 元寇（文永の役・弘安の役） |
| 1333年 | 鎌倉幕府が滅びる |

### ダンジョンの問題

**KA1** キャラ: 守護地頭ゴブリン
- 問題: 源頼朝が、朝廷に守護・地頭を置くことを認めさせたのは、何年じゃ？
- 正解: **1185年**
- 誤り: 1192年 / 1221年 / 1232年
- 解説: 1185年、壇ノ浦で平氏が滅びたあと、頼朝は朝廷に守護・地頭を置くことを認めさせたのじゃ。これで全国に武士の支配が広がったぞ。

**KA2** キャラ: 将軍ゴースト
- 問題: 源頼朝が、朝廷から征夷大将軍に任じられたのは、何年じゃ？
- 正解: **1192年**
- 誤り: 1185年 / 1221年 / 1333年
- 解説: 1192年、源頼朝が征夷大将軍に任じられたのじゃ。守護・地頭が置かれた1185年とまちがえぬようにな。

**KA3** キャラ: 上皇スケルトン
- 問題: 後鳥羽上皇が、幕府を倒そうと兵をあげたが敗れた承久の乱は、何年じゃ？
- 正解: **1221年**
- 誤り: 1185年 / 1232年 / 1274年
- 解説: 1221年、後鳥羽上皇が北条義時を倒そうと兵をあげたが、幕府軍に敗れたのじゃ。このあと京都に六波羅探題が置かれたぞ。

**KA4** キャラ: 式目スライム
- 問題: 北条泰時が、武士の裁判の基準として御成敗式目を定めたのは、何年じゃ？
- 正解: **1232年**
- 誤り: 1185年 / 1221年 / 1274年
- 解説: 1232年、執権の北条泰時が、武士のための最初の法である御成敗式目（貞永式目）を定めたのじゃ。

**KA5** キャラ: 元寇ナイト
- 問題: 元の大軍が九州北部にせめてきた文永の役は、何年じゃ？
- 正解: **1274年**
- 誤り: 1221年 / 1281年 / 1333年
- 解説: 1274年、元の大軍が九州北部にせめてきたのじゃ（文永の役）。1281年には再びせめてきた（弘安の役）が、どちらも幕府は退けたぞ。

**KA6** キャラ: 幕府ゴーレム
- 問題: 後醍醐天皇の呼びかけに応じた足利尊氏や新田義貞らにより、鎌倉幕府が滅んだのは、何年じゃ？
- 正解: **1333年**
- 誤り: 1221年 / 1274年 / 1338年
- 解説: 1333年、足利尊氏らが六波羅探題を、新田義貞らが鎌倉をせめ、鎌倉幕府が滅んだのじゃ。

## 室町時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 室町時代は、足利尊氏が京都に幕府を開いて始まった時代じゃ。3代将軍の足利義満のころに、幕府は最も栄えたのじゃ。
2. 民衆の力が強くなり、土一揆が各地で起こったぞ。都では、将軍のあとつぎ争いから応仁の乱が起こったのじゃ。
3. 応仁の乱のあとは、各地の大名が争う戦国時代になる。1338年・1392年・1404年・1428年・1467年・1543年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1338年 | 足利尊氏が征夷大将軍になる |
| 1392年 | 南北朝が合一する |
| 1404年 | 日明貿易（勘合貿易）が始まる |
| 1428年 | 正長の土一揆 |
| 1467年 | 応仁の乱が始まる |
| 1543年 | 鉄砲が伝わる |

### ダンジョンの問題

**M1** キャラ: 尊氏ゴースト
- 問題: 足利尊氏が、北朝の天皇から征夷大将軍に任じられたのは、何年じゃ？
- 正解: **1338年**
- 誤り: 1192年 / 1333年 / 1392年
- 解説: 1338年、足利尊氏が征夷大将軍に任じられ、京都に室町幕府を開いたのじゃ。

**M2** キャラ: 南北朝スケルトン
- 問題: 足利義満が、南朝と北朝を1つにまとめて、南北朝の争いを終わらせたのは、何年じゃ？
- 正解: **1392年**
- 誤り: 1338年 / 1404年 / 1467年
- 解説: 1392年、3代将軍の足利義満が南朝と北朝を合わせ、約60年続いた南北朝の争いを終わらせたのじゃ。

**M3** キャラ: 勘合ゴブリン
- 問題: 足利義満が、明と勘合を使った貿易を始めたのは、何年じゃ？
- 正解: **1404年**
- 誤り: 1338年 / 1392年 / 1428年
- 解説: 1404年、足利義満が明との勘合貿易（日明貿易）を始めたのじゃ。倭寇と区別するために勘合という合い札を使ったぞ。

**M4** キャラ: 一揆スライム
- 問題: 近江の馬借らが中心となって徳政を求め、近畿地方に広がった正長の土一揆が起こったのは、何年じゃ？
- 正解: **1428年**
- 誤り: 1392年 / 1404年 / 1467年
- 解説: 1428年、正長の土一揆が起こったのじゃ。民衆が借金の帳消し（徳政）を求めて、酒屋や土倉をおそったぞ。

**M5** キャラ: 応仁ナイト
- 問題: 将軍のあとつぎ争いや、細川氏・山名氏の対立から、京都を中心に起こった応仁の乱は、何年に始まったのじゃ？
- 正解: **1467年**
- 誤り: 1428年 / 1488年 / 1543年
- 解説: 1467年、応仁の乱が始まり、約11年続いたのじゃ。これで幕府の力が弱まり、戦国時代になっていくぞ。

**M6** キャラ: 種子島ゴースト
- 問題: 種子島にポルトガル人が漂着し、日本に鉄砲が伝わったのは、何年じゃ？
- 正解: **1543年**
- 誤り: 1467年 / 1549年 / 1573年
- 解説: 1543年、種子島に漂着したポルトガル人によって鉄砲が伝わったのじゃ。戦い方が大きく変わっていったぞ。

## 安土桃山時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 安土桃山時代は、織田信長と豊臣秀吉が、乱れた世の中をまとめていった時代じゃ。
2. 信長は足利義昭を追放して室町幕府を終わらせ、秀吉は検地や刀狩で、武士と農民の身分を分ける社会をつくったのじゃ。
3. 信長の天下統一の動きから、秀吉の全国統一と朝鮮出兵までをおさえよう！ 1573年・1575年・1582年・1588年・1590年・1592年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1573年 | 室町幕府が滅びる |
| 1575年 | 長篠の戦い |
| 1582年 | 本能寺の変 |
| 1588年 | 刀狩令が出される |
| 1590年 | 秀吉が全国を統一する |
| 1592年 | 文禄の役（朝鮮出兵） |

### ダンジョンの問題

**AZ1** キャラ: 義昭ゴースト
- 問題: 織田信長が、足利義昭を京都から追放し、室町幕府を滅ぼしたのは、何年じゃ？
- 正解: **1573年**
- 誤り: 1467年 / 1575年 / 1582年
- 解説: 1573年、織田信長が15代将軍の足利義昭を京都から追放し、室町幕府が滅びたのじゃ。

**AZ2** キャラ: 鉄砲スケルトン
- 問題: 織田信長・徳川家康の連合軍が、鉄砲を使って武田氏の騎馬隊を破った長篠の戦いは、何年じゃ？
- 正解: **1575年**
- 誤り: 1543年 / 1573年 / 1582年
- 解説: 1575年、長篠の戦いで織田・徳川の連合軍が、鉄砲隊を使って武田勝頼の騎馬隊を破ったのじゃ。

**AZ3** キャラ: 本能寺ゴブリン
- 問題: 明智光秀が、京都の本能寺で織田信長をおそった本能寺の変は、何年じゃ？
- 正解: **1582年**
- 誤り: 1573年 / 1575年 / 1590年
- 解説: 1582年、家臣の明智光秀が本能寺で織田信長をおそい、信長は自害したのじゃ。そのあと、豊臣秀吉が光秀を倒して力をのばしたぞ。

**AZ4** キャラ: 刀狩ゴーレム
- 問題: 豊臣秀吉が、農民から刀ややりなどの武器を取り上げる刀狩令を出したのは、何年じゃ？
- 正解: **1588年**
- 誤り: 1582年 / 1590年 / 1592年
- 解説: 1588年、豊臣秀吉が刀狩令を出し、農民の武器を取り上げたのじゃ。一揆を防ぎ、武士と農民の身分を分けるためじゃ。

**AZ5** キャラ: 小田原スライム
- 問題: 豊臣秀吉が、小田原の北条氏を滅ぼして、全国を統一したのは、何年じゃ？
- 正解: **1590年**
- 誤り: 1582年 / 1588年 / 1592年
- 解説: 1590年、秀吉は小田原の北条氏を滅ぼし、東北の大名も従えて、全国を統一したのじゃ。

**AZ6** キャラ: 朝鮮ナイト
- 問題: 豊臣秀吉が、明の征服をめざして朝鮮に出兵した文禄の役は、何年に始まったのじゃ？
- 正解: **1592年**
- 誤り: 1582年 / 1588年 / 1590年
- 解説: 1592年、秀吉が朝鮮に大軍を送り、文禄の役が始まったのじゃ。1597年には再び出兵した（慶長の役）が、秀吉の死で引き上げたぞ。

## 要確認（年や表現が揺れる項目）

| 項目 | 揺れの内容 | 下書きでの扱い |
|---|---|---|
| 鎌倉幕府の成立（KA1・KA2） | 成立年は1185年説（守護・地頭の設置）、1192年説（征夷大将軍）などがあり、教科書でも扱いが異なる | 「幕府成立」ではなく、出来事ごと（守護・地頭の設置＝1185年、征夷大将軍＝1192年）に問う |
| 承久の乱（KA3） | 1221年で一般的。上皇が倒そうとした相手を「北条義時」とする表現は、教材によって「幕府」とも書く | 解説で北条義時と記載 |
| 御成敗式目（KA4） | 1232年（貞永元年）で一般的。「貞永式目」とも呼ぶ | 併記 |
| 元寇（KA5） | 文永の役1274年、弘安の役1281年。誤りの選択肢に1281年を入れており難しめ | このまま |
| 鎌倉幕府の滅亡（KA6） | 1333年。1338年（尊氏の将軍就任）を誤りの選択肢に使用 | このまま |
| 室町幕府の成立（M1） | 幕府の成立は、建武式目（1336年）とする説もある。1338年は「征夷大将軍に任じられた年」 | 「征夷大将軍に任じられた年」として問う |
| 勘合貿易の開始（M3） | 1401年に義満が明へ使いを送った説もあるが、教科書では1404年が一般的 | 1404年を採用 |
| 正長の土一揆（M4） | 1428年で一般的。「馬借」が発端とされる | 1428年を採用 |
| 応仁の乱（M5） | 1467年に始まり、1477年に終わる | 「始まった年」として問う |
| 鉄砲伝来（M6） | 1543年が一般的（1542年説もある）。ポルトガル人の漂着＝種子島 | 1543年を採用。1549年（キリスト教伝来）は誤りの選択肢に使用 |
| 室町幕府の滅亡（AZ1） | 1573年の義昭の追放を幕府の滅亡とするのが一般的 | 1573年を採用 |
| 刀狩令（AZ4） | 1588年（天正16年）で一般的 | 1588年を採用 |
| 全国統一（AZ5） | 1590年の小田原攻めと東北平定を全国統一とするのが一般的 | 1590年を採用 |
| 時代の区切り | 鉄砲伝来（1543年）は戦国時代のできごとで、教科書によっては室町時代に含める。1600年（関ヶ原）以降は次の弾（江戸）に回す | 鉄砲伝来は室町に入れた |
| キャラ名・語尾 | 「〜じゃ」のコミカル口調は私の案 | 変更可 |

## 確認のお願い

- 各問題の正解・誤りの選択肢・解説に、間違いや言い過ぎがないか
- 「誤り」の選択肢が、別の事柄では正解になりうるもの（紛らわしすぎるもの）になっていないか
- 難関高校の対策として、足りない重要年号（例: 建武の新政、キリスト教伝来、太閤検地など）の追加希望
