## 江戸時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 江戸時代は、徳川家康が江戸に幕府を開いて始まった、約260年続いた時代じゃ。
2. 幕府は大名を厳しく取りしまり、鎖国で外国との交流を制限した。やがて財政が苦しくなり、三つの大きな改革が行われたのじゃ。
3. 幕末には、ペリーの来航で開国をせまられ、幕府は終わりに向かう。1603年・1716年・1787年・1841年・1853年・1867年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1603年 | 徳川家康が江戸幕府を開く |
| 1716年 | 享保の改革が始まる |
| 1787年 | 寛政の改革が始まる |
| 1841年 | 天保の改革が始まる |
| 1853年 | ペリーが浦賀に来航する |
| 1867年 | 大政奉還が行われる |

### ダンジョンの問題

**E1** キャラ: 家康ゴースト
- 問題: 徳川家康が征夷大将軍に任じられ、江戸に幕府を開いたのは、何年じゃ？
- 正解: **1603年**
- 誤り: 1600年 / 1615年 / 1716年
- 解説: 1603年、徳川家康が征夷大将軍に任じられ、江戸幕府を開いたのじゃ。関ヶ原の戦いは、その3年前の1600年じゃぞ。

**E2** キャラ: 吉宗ゴブリン
- 問題: 8代将軍の徳川吉宗が、財政の立て直しをめざして享保の改革を始めたのは、何年じゃ？
- 正解: **1716年**
- 誤り: 1603年 / 1787年 / 1841年
- 解説: 1716年、8代将軍の徳川吉宗が享保の改革を始めたのじゃ。倹約や、目安箱の設置、公事方御定書の制定などを行ったぞ。

**E3** キャラ: 定信スケルトン
- 問題: 老中の松平定信が、倹約や政治の引きしめを行った寛政の改革を始めたのは、何年じゃ？
- 正解: **1787年**
- 誤り: 1716年 / 1841年 / 1853年
- 解説: 1787年、老中の松平定信が寛政の改革を始めたのじゃ。ききんに備えて米をたくわえさせ、旗本・御家人の借金を帳消しにしたぞ。

**E4** キャラ: 忠邦スライム
- 問題: 老中の水野忠邦が、株仲間の解散などを行った天保の改革を始めたのは、何年じゃ？
- 正解: **1841年**
- 誤り: 1716年 / 1787年 / 1853年
- 解説: 1841年、老中の水野忠邦が天保の改革を始めたのじゃ。物価を下げるために株仲間を解散させたが、うまくいかなかったぞ。

**E5** キャラ: 黒船ナイト
- 問題: アメリカのペリーが、4隻の軍艦を率いて浦賀に来航し、開国を求めたのは、何年じゃ？
- 正解: **1853年**
- 誤り: 1841年 / 1854年 / 1867年
- 解説: 1853年、ペリーが浦賀に来航して開国を求めたのじゃ。翌1854年には、日米和親条約が結ばれたぞ。

**E6** キャラ: 慶喜ゴースト
- 問題: 15代将軍の徳川慶喜が、政権を朝廷に返した大政奉還が行われたのは、何年じゃ？
- 正解: **1867年**
- 誤り: 1853年 / 1858年 / 1868年
- 解説: 1867年、徳川慶喜が政権を朝廷に返したのじゃ（大政奉還）。これで江戸幕府は幕を閉じたぞ。

## 明治時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 明治時代は、1868年に元号が明治に改まり、天皇を中心とする新しい国づくりが始まった時代じゃ。
2. 廃藩置県や地租改正で国のしくみを整え、「富国強兵」をめざして近代化を進めたのじゃ。
3. 憲法をつくって議会を開き、日清・日露戦争を経て、日本は大国の仲間入りをした。1871年・1873年・1889年・1894年・1904年・1910年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1871年 | 廃藩置県が行われる |
| 1873年 | 地租改正が始まる |
| 1889年 | 大日本帝国憲法が発布される |
| 1894年 | 日清戦争が始まる |
| 1904年 | 日露戦争が始まる |
| 1910年 | 韓国併合が行われる |

### ダンジョンの問題

**ME1** キャラ: 廃藩ゴブリン
- 問題: 明治政府が藩を廃止して、府と県を置いた廃藩置県を行ったのは、何年じゃ？
- 正解: **1871年**
- 誤り: 1868年 / 1873年 / 1889年
- 解説: 1871年、明治政府が廃藩置県を行い、藩をなくして府と県を置いたのじゃ。政府が任命した府知事・県令が、各地を治めたぞ。

**ME2** キャラ: 地租ゴースト
- 問題: 土地の値段（地価）を基準に、税を現金で納めさせる地租改正が始まったのは、何年じゃ？
- 正解: **1873年**
- 誤り: 1871年 / 1877年 / 1889年
- 解説: 1873年、地租改正が始まり、地価の3%を現金で納めることになったのじゃ。同じ年には徴兵令も出されたぞ。

**ME3** キャラ: 憲法スケルトン
- 問題: 伊藤博文らがつくった大日本帝国憲法が発布されたのは、何年じゃ？
- 正解: **1889年**
- 誤り: 1885年 / 1890年 / 1894年
- 解説: 1889年、大日本帝国憲法が発布されたのじゃ。翌1890年には、第1回の帝国議会が開かれたぞ。

**ME4** キャラ: 日清スライム
- 問題: 朝鮮をめぐって日本と清が争った日清戦争が始まったのは、何年じゃ？
- 正解: **1894年**
- 誤り: 1889年 / 1895年 / 1904年
- 解説: 1894年、日清戦争が始まったのじゃ。翌1895年に下関条約が結ばれ、日本は清から賠償金などを得たぞ。

**ME5** キャラ: 日露ナイト
- 問題: 満州や朝鮮をめぐって日本とロシアが争った日露戦争が始まったのは、何年じゃ？
- 正解: **1904年**
- 誤り: 1894年 / 1902年 / 1905年
- 解説: 1904年、日露戦争が始まったのじゃ。翌1905年にポーツマス条約が結ばれ、戦争は終わったぞ。

**ME6** キャラ: 併合ゴーレム
- 問題: 日本が韓国を併合して、植民地にした韓国併合が行われたのは、何年じゃ？
- 正解: **1910年**
- 誤り: 1904年 / 1905年 / 1911年
- 解説: 1910年、日本が韓国を併合し、朝鮮総督府を置いて植民地としたのじゃ。

## 要確認（年や表現が揺れる項目）

| 項目 | 揺れの内容 | 下書きでの扱い |
|---|---|---|
| 江戸幕府の成立（E1） | 1603年（征夷大将軍任命）が一般的。関ヶ原の戦い（1600年）と近く、選択肢の紛らわしさに注意 | 1603年を採用。1600年は誤りの選択肢に使用 |
| 三大改革の開始年（E2〜E4） | 享保の改革は1716年、寛政の改革は1787年、天保の改革は1841年が教科書で一般的。いずれも「始まった年」として問う | 「始めた」と表現 |

| 明治の始まり | 1868年（明治改元）とするのが一般的。廃藩置県以降の年号を問題にしており、1868年は問題にしていない | 解説文にのみ記載 |

## 確認のお願い

- 各問題の正解・誤りの選択肢・解説に、間違いや言い過ぎがないか
- 「誤り」の選択肢が、別の事柄では正解になりうるもの（紛らわしすぎるもの）になっていないか
- 難関高校の対策として、足りない重要年号（例: 島原・天草一揆、日米修好通商条約、西南戦争、内閣制度など）の追加希望
