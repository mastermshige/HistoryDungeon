## 【相談】昭和時代を2つに分ける案

昭和は約63年間と長く、重要年号も多いため、**「昭和時代（戦前・戦中）」と「昭和時代（戦後）」の2つの時代に分ける**案にしています。
そのぶん教室と出題がもう1周増えますが、1つの時代あたりの問題数（6問）を、ほかの時代と同じ量に保てます。
分けずに1つにする場合は、年号を6つに絞り直します（希望があればお知らせください）。

## 大正時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 大正時代は、1912年に元号が大正に改まって始まった時代じゃ。民主主義を求める「大正デモクラシー」の動きが広まったのじゃ。
2. 第一次世界大戦で日本は好景気になったが、物価が上がって米騒動が起こるなど、暮らしに苦しむ人も多かった。
3. 関東大震災の被害をのりこえ、普通選挙法が成立した。1914年・1915年・1918年・1920年・1923年・1925年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1914年 | 第一次世界大戦が始まる |
| 1915年 | 二十一か条の要求 |
| 1918年 | 米騒動 |
| 1920年 | 国際連盟が発足する |
| 1923年 | 関東大震災 |
| 1925年 | 普通選挙法が成立する |

### ダンジョンの問題

**T1** キャラ: 参戦ゴブリン
- 問題: 日本が日英同盟を理由にドイツに宣戦布告し、第一次世界大戦に参戦したのは、何年じゃ？
- 正解: **1914年**
- 誤り: 1904年 / 1915年 / 1918年
- 解説: 1914年、第一次世界大戦が始まり、日本は日英同盟を理由にドイツに宣戦布告して参戦したのじゃ。

**T2** キャラ: 要求ゴースト
- 問題: 日本が中国に、山東省のドイツの権益を引きつぐことなどを求めた二十一か条の要求を出したのは、何年じゃ？
- 正解: **1915年**
- 誤り: 1914年 / 1919年 / 1925年
- 解説: 1915年、日本は中国に二十一か条の要求を出し、大部分を認めさせたのじゃ。中国では強い反日運動が起こったぞ。

**T3** キャラ: 米騒動スライム
- 問題: 米の値段が急に上がり、富山県の漁村の女性たちをきっかけに全国へ広がった米騒動が起こったのは、何年じゃ？
- 正解: **1918年**
- 誤り: 1914年 / 1915年 / 1923年
- 解説: 1918年、米の値上がりに苦しむ人々が米騒動を起こしたのじゃ。これで寺内正毅内閣が退陣し、原敬の政党内閣が生まれたぞ。

**T4** キャラ: 連盟ナイト
- 問題: 第一次世界大戦のあと、平和を守るための国際連盟が発足し、日本が常任理事国になったのは、何年じゃ？
- 正解: **1920年**
- 誤り: 1914年 / 1919年 / 1923年
- 解説: 1920年、国際連盟が発足し、日本は常任理事国になったのじゃ。提案したアメリカは、議会の反対で加盟しなかったぞ。

**T5** キャラ: 記録スケルトン
- 問題: 関東地方をおそい、東京や横浜に大きな被害を出した関東大震災が起こったのは、何年じゃ？
- 正解: **1923年**
- 誤り: 1918年 / 1920年 / 1925年
- 解説: 1923年9月1日、関東大震災が起こり、東京や横浜を中心に大きな被害が出たのじゃ。

**T6** キャラ: 選挙ゴーレム
- 問題: 満25歳以上のすべての男子に選挙権があたえられた普通選挙法が成立したのは、何年じゃ？
- 正解: **1925年**
- 誤り: 1918年 / 1923年 / 1928年
- 解説: 1925年、普通選挙法が成立し、満25歳以上のすべての男子に選挙権があたえられたのじゃ。同じ年に治安維持法も出されたぞ。

## 昭和時代（戦前・戦中）（問題 6問）

### 教室の解説（黒板・3ページ）

1. 昭和時代は、1926年に始まった、日本が大きく変わった時代じゃ。まずは、昭和のはじめから戦争が終わるまでを学ぶぞ。
2. 世界恐慌で不景気になると、軍部が力をのばし、満州事変や日中戦争へと進んでいった。1933年には日本が国際連盟を脱退し、1936年には二・二六事件が起こったのじゃ。
3. 戦争は太平洋戦争へと広がり、1945年に日本が降伏して終わった。1929年・1931年・1932年・1937年・1941年・1945年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1929年 | 世界恐慌が始まる |
| 1931年 | 満州事変が起こる |
| 1932年 | 五・一五事件が起こる |
| 1937年 | 日中戦争が始まる |
| 1941年 | 太平洋戦争が始まる |
| 1945年 | 日本が降伏する |

### ダンジョンの問題

**S1** キャラ: 恐慌ゴースト
- 問題: アメリカのニューヨークで株価が大暴落し、世界恐慌が始まったのは、何年じゃ？
- 正解: **1929年**
- 誤り: 1923年 / 1931年 / 1937年
- 解説: 1929年、ニューヨークの株式市場で株価が大暴落し、世界中に不景気が広がる世界恐慌が始まったのじゃ。

**S2** キャラ: 満州ゴーレム
- 問題: 関東軍が柳条湖で南満州鉄道の線路を爆破し、満州の大部分を占領する戦いに広がった満州事変が起こったのは、何年じゃ？
- 正解: **1931年**
- 誤り: 1929年 / 1932年 / 1937年
- 解説: 1931年、関東軍が柳条湖で鉄道を爆破し、満州事変が起こったのじゃ。翌1932年には満州国の建国が宣言されたぞ。

**S3** キャラ: 首相スケルトン
- 問題: 海軍の青年将校らが、犬養毅首相を暗殺した五・一五事件が起こったのは、何年じゃ？
- 正解: **1932年**
- 誤り: 1931年 / 1933年 / 1936年
- 解説: 1932年、海軍の青年将校らが犬養毅首相を暗殺したのじゃ。これで政党内閣の時代が終わったぞ。

**S4** キャラ: 盧溝橋ゴブリン
- 問題: 北京郊外の盧溝橋で日本軍と中国軍が衝突し、日中戦争が始まったのは、何年じゃ？
- 正解: **1937年**
- 誤り: 1931年 / 1936年 / 1941年
- 解説: 1937年、盧溝橋事件をきっかけに日中戦争が始まり、戦いは全面的なものになったのじゃ。

**S5** キャラ: 開戦ナイト
- 問題: 日本がハワイの真珠湾を攻撃し、アメリカ・イギリスとの太平洋戦争が始まったのは、何年じゃ？
- 正解: **1941年**
- 誤り: 1937年 / 1939年 / 1945年
- 解説: 1941年12月、日本がハワイの真珠湾などを攻撃し、太平洋戦争が始まったのじゃ。

**S6** キャラ: 終戦スライム
- 問題: 広島と長崎に原子爆弾が落とされ、日本がポツダム宣言を受け入れて降伏し、戦争が終わったのは、何年じゃ？
- 正解: **1945年**
- 誤り: 1941年 / 1946年 / 1951年
- 解説: 1945年、広島と長崎に原子爆弾が落とされ、日本はポツダム宣言を受け入れて降伏したのじゃ。これで第二次世界大戦が終わったぞ。

## 昭和時代（戦後）（問題 6問）

### 教室の解説（黒板・3ページ）

1. 戦後の昭和は、日本が戦争のあとに民主的な国へ生まれ変わり、経済を大きく成長させた時代じゃ。
2. GHQの指導で民主化が進み、日本国憲法がつくられた。独立を回復し、国際社会にも復帰したのじゃ。
3. 高度経済成長で暮らしが豊かになったが、石油危機で終わりをむかえた。1946年・1951年・1956年・1964年・1972年・1973年が大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1946年 | 日本国憲法が公布される |
| 1951年 | サンフランシスコ平和条約に調印する |
| 1956年 | 日本が国際連合に加盟する |
| 1964年 | 東京オリンピックが開かれる |
| 1972年 | 沖縄が日本に復帰する |
| 1973年 | 石油危機が起こる |

### ダンジョンの問題

**SW1** キャラ: 憲法ゴースト
- 問題: 日本国憲法が公布されたのは、何年じゃ？
- 正解: **1946年**
- 誤り: 1945年 / 1947年 / 1951年
- 解説: 1946年11月3日、日本国憲法が公布されたのじゃ。施行されたのは、翌1947年の5月3日じゃぞ。

**SW2** キャラ: 独立スケルトン
- 問題: 吉田茂内閣が、サンフランシスコ平和条約に調印し、同時に日米安全保障条約を結んだのは、何年じゃ？
- 正解: **1951年**
- 誤り: 1946年 / 1952年 / 1956年
- 解説: 1951年、吉田茂内閣がサンフランシスコ平和条約に調印し、同時に日米安全保障条約を結んだのじゃ。条約が発効した翌1952年に、日本は独立を回復したぞ。

**SW3** キャラ: 国連ゴブリン
- 問題: 日ソ共同宣言に調印して、ソ連との国交が回復し、日本が国際連合に加盟したのは、何年じゃ？
- 正解: **1956年**
- 誤り: 1951年 / 1960年 / 1964年
- 解説: 1956年、日ソ共同宣言でソ連との国交が回復し、日本の国際連合への加盟が実現したのじゃ。

**SW4** キャラ: 五輪ナイト
- 問題: アジアで初めてのオリンピックが東京で開かれ、東海道新幹線が開業したのは、何年じゃ？
- 正解: **1964年**
- 誤り: 1956年 / 1960年 / 1972年
- 解説: 1964年、東京でオリンピックが開かれ、開会にあわせて東海道新幹線が開業したのじゃ。高度経済成長のころの出来事じゃ。

**SW5** キャラ: 沖縄スライム
- 問題: アメリカの統治下にあった沖縄が、日本に復帰したのは、何年じゃ？
- 正解: **1972年**
- 誤り: 1964年 / 1973年 / 1978年
- 解説: 1972年、沖縄が日本に復帰したのじゃ。同じ年には、日中共同声明で中国との国交も正常化されたぞ。

**SW6** キャラ: 石油ゴーレム
- 問題: 第四次中東戦争をきっかけに石油危機（オイル・ショック）が起こり、高度経済成長が終わったのは、何年じゃ？
- 正解: **1973年**
- 誤り: 1964年 / 1972年 / 1978年
- 解説: 1973年、第四次中東戦争をきっかけに石油危機が起こり、物価が急に上がったのじゃ。これで高度経済成長が終わったぞ。

## 平成時代（問題 6問）

### 教室の解説（黒板・3ページ）

1. 平成時代は、1989年に昭和天皇が亡くなり、元号が平成に改まって始まった時代じゃ。この年には消費税も導入されたのじゃ。
2. 冷戦が終わって世界が大きく変わり、日本ではバブル経済が崩壊して、長い不景気が続いた。
3. 大きな震災やテロ、金融危機が続いた時代じゃ。1989年・1991年・1995年・2001年・2008年・2011年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 1989年 | 平成に改元、消費税が導入される |
| 1991年 | バブル経済が崩壊する |
| 1995年 | 阪神・淡路大震災 |
| 2001年 | アメリカ同時多発テロ |
| 2008年 | リーマン・ショック |
| 2011年 | 東日本大震災 |

### ダンジョンの問題

**H1** キャラ: 改元ゴブリン
- 問題: 元号が昭和から平成に改まり、税率3%の消費税が導入されたのは、何年じゃ？
- 正解: **1989年**
- 誤り: 1985年 / 1991年 / 1997年
- 解説: 1989年、昭和天皇が亡くなって元号が平成に改まり、税率3%の消費税が導入されたのじゃ。消費税が5%に上がったのは1997年じゃぞ。

**H2** キャラ: バブルゴースト
- 問題: 株価や地価が急に下がり、バブル経済が崩壊して、長い不景気に入ったとされる年は、何年じゃ？
- 正解: **1991年**
- 誤り: 1985年 / 1989年 / 1995年
- 解説: 1991年ごろ、株価や地価の急な下落でバブル経済が崩壊したのじゃ。その後、日本は長い不景気に入ったぞ。

**H3** キャラ: 防災スケルトン
- 問題: 兵庫県南部を中心に大きな被害を出した阪神・淡路大震災が起こったのは、何年じゃ？
- 正解: **1995年**
- 誤り: 1991年 / 1993年 / 2011年
- 解説: 1995年1月17日、阪神・淡路大震災が起こり、大きな被害が出たのじゃ。この年は、ボランティア元年とも呼ばれるぞ。

**H4** キャラ: 同時テロナイト
- 問題: アメリカで、旅客機が高層ビルなどに突っ込む同時多発テロが起こったのは、何年じゃ？
- 正解: **2001年**
- 誤り: 1995年 / 2003年 / 2008年
- 解説: 2001年9月11日、アメリカで同時多発テロが起こったのじゃ。アメリカは、そのあとアフガニスタンへの攻撃を始めたぞ。

**H5** キャラ: 金融ゴーレム
- 問題: アメリカの大手証券会社リーマン・ブラザーズが破綻し、世界中に金融危機が広がったのは、何年じゃ？
- 正解: **2008年**
- 誤り: 2001年 / 2003年 / 2011年
- 解説: 2008年、リーマン・ブラザーズが破綻し、世界金融危機が起こったのじゃ。日本でも景気が悪くなったぞ。

**H6** キャラ: 復興スライム
- 問題: 東北地方の太平洋側をおそい、大きな津波や原子力発電所の事故をもたらした東日本大震災が起こったのは、何年じゃ？
- 正解: **2011年**
- 誤り: 1995年 / 2008年 / 2014年
- 解説: 2011年3月11日、東日本大震災が起こり、大きな津波が東北地方の太平洋側をおそったのじゃ。福島第一原子力発電所でも事故が起こったぞ。

## 要確認（年や表現が揺れる項目）

| 項目 | 揺れの内容 | 下書きでの扱い |

| 昭和の分割 | 昭和を1つの時代とするか、2つに分けるか | 2つに分ける案（上の「相談」を参照）。分けない場合は年号を6つに絞る |
| 第一次世界大戦（T1） | 開戦は1914年7月。日本の参戦は同年8月。誤りの選択肢に1904年（日露戦争）を使用 | 「日本が参戦した年」として1914年を採用 |
| 国際連盟（T4） | 発足は1920年1月。パリ講和会議・ヴェルサイユ条約は1919年で、誤りの選択肢に使用 | 1920年を採用 |
| 普通選挙法（T6） | 成立は1925年。実際の普通選挙の実施は1928年で、誤りの選択肢に使用 | 「成立した年」として問う |
| 世界恐慌（S1） | 1929年10月の株価大暴落が発端 | 1929年を採用 |
| 五・一五事件（S3） | 1932年。誤りの選択肢の1933年（国際連盟脱退）、1936年（二・二六事件）は解説文で説明 | このまま |
| 日中戦争（S4） | 盧溝橋事件は1937年7月7日。戦争の始まりを1931年（満州事変）とする見方もある | 1937年を採用 |
| 太平洋戦争（S5） | 1941年12月8日（日本時間）。マレー半島への上陸と真珠湾攻撃 | 1941年を採用 |
| 終戦（S6） | ポツダム宣言の受諾（8月14日）、玉音放送（8月15日）、降伏文書の調印（9月2日）がすべて1945年 | 1945年を採用 |

| 石油危機（SW6） | 1973年10月の第四次中東戦争が発端 | 1973年を採用 |
| 消費税（H1） | 1989年4月に3%で導入。1997年に5%、2014年に8% | 1989年を採用 |
| バブル経済の崩壊（H2） | 崩壊の時期は資料によって1990年〜1992年ごろとされる。教科書では「1991年」と書かれることが多い | 「1991年ごろ」と表現して1991年を採用（要確認） |
| リーマン・ショック（H5） | 2008年9月15日 | このまま |
| 東日本大震災（H6） | 2011年3月11日 | このまま |

## 確認のお願い

- 各問題の正解・誤りの選択肢・解説に、間違いや言い過ぎがないか
- 戦争・震災・テロの問題の表現（キャラ名と口調を含む）が、適切か
- 昭和を2つに分ける案でよいか
- 難関高校の対策として、足りない重要年号（例: 二・二六事件、日米安全保障条約の改定、日中国交正常化、55年体制の終わりなど）の追加希望
