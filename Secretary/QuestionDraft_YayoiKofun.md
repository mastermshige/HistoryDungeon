## 弥生時代

### 教室の解説（黒板・3ページ）

1. 弥生時代は、大陸から稲作と金属器（青銅器・鉄器）が伝わり、米づくりが広まった時代じゃ。
2. 米づくりで貧富の差が生まれ、ムラどうしの争いから、小さな国（クニ）ができていったのじゃ。
3. 中国の歴史書には、倭（日本）の国々の様子が書かれておる。57年・107年・239年の3つの年号は特に大事じゃ！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 57年 | 奴国の王が後漢に使いを送り、金印を授かる |
| 107年 | 倭国王帥升らが後漢に生口を献上する |
| 239年 | 邪馬台国の卑弥呼が魏に使いを送る |

### ダンジョンの問題（4問）

**Y1** キャラ: 金印カメ
- 問題: 奴国の王が後漢の光武帝から金印を授かったのは、何年じゃ？
- 正解: **57年**
- 誤り: 107年 / 239年 / 391年
- 解説: 57年、倭の奴国の王が後漢の光武帝に使いを送り、金印を授かったのじゃ。この記録は『後漢書』東夷伝にあるぞ。

**Y2** キャラ: 生口ゴーレム
- 問題: 倭国王の帥升らが、後漢の皇帝に生口（奴隷）160人を献上したのは、何年じゃ？
- 正解: **107年**
- 誤り: 57年 / 239年 / 478年
- 解説: 107年、倭国王の帥升らが後漢の安帝に生口160人を献上したのじゃ。これも『後漢書』東夷伝に書かれておる。

**Y3** キャラ: 銅鏡ゴースト
- 問題: 邪馬台国の女王が魏に使いを送り、「親魏倭王」の称号と金印、銅鏡100枚を授かったのは、何年じゃ？
- 正解: **239年**
- 誤り: 57年 / 107年 / 478年
- 解説: 239年、邪馬台国の女王・卑弥呼が魏に使いを送り、「親魏倭王」の称号などを授かったのじゃ。『魏志』倭人伝に書かれておるぞ。

**Y4** キャラ: 環濠ゴブリン
- 問題: 弥生時代の大規模な環濠集落の跡で、佐賀県にある遺跡はどれじゃ？
- 正解: **吉野ヶ里遺跡**
- 誤り: 三内丸山遺跡 / 大森貝塚 / 岩宿遺跡
- 解説: 吉野ヶ里遺跡は佐賀県にある弥生時代の大規模な環濠集落跡じゃ。三内丸山遺跡は縄文、岩宿遺跡は旧石器時代の遺跡じゃぞ。

## 古墳時代

### 教室の解説（黒板・3ページ）

1. 古墳時代は、3世紀後半ごろから、各地に大きな古墳（お墓）がつくられた時代じゃ。
2. 近畿地方の有力者たちが集まったヤマト政権（大和政権）が、大王を中心に各地の豪族をまとめていったのじゃ。
3. ヤマト政権は朝鮮半島にも進出し、中国の宋にも使いを送った。391年・421年・478年・527年をおぼえよう！

### 年表（黒板の右側）

| 年号 | 出来事 |
|---|---|
| 391年 | 倭が海を渡り朝鮮半島に出兵する（好太王碑文） |
| 421年 | 倭王讃が宋に使いを送る |
| 478年 | 倭王武が宋の皇帝に上表文を送る |
| 527年 | 筑紫国造磐井の乱が起こる |

### ダンジョンの問題（4問）

**K1** キャラ: 碑文スケルトン
- 問題: 高句麗の好太王碑に、倭が海を渡って朝鮮半島に出兵したと記されている年は、何年じゃ？
- 正解: **391年**
- 誤り: 421年 / 478年 / 527年
- 解説: 好太王碑文には、391年に倭が海を渡って朝鮮半島に進出し、高句麗と戦ったことが記されておるのじゃ。

**K2** キャラ: 埴輪ナイト
- 問題: 倭王の讃が、中国の宋に使いを送ったのは、何年じゃ？
- 正解: **421年**
- 誤り: 391年 / 478年 / 527年
- 解説: 421年、倭王の讃が宋に使いを送ったのじゃ。讃・珍・済・興・武の5人の王を「倭の五王」と呼ぶぞ。

**K3** キャラ: 上表文ゴースト
- 問題: 倭王の武が、宋の皇帝に上表文を送ったのは、何年じゃ？
- 正解: **478年**
- 誤り: 391年 / 421年 / 527年
- 解説: 478年、倭の五王の最後の武が宋の順帝に上表文を送り、朝鮮半島での立場を認めてもらおうとしたのじゃ。武は雄略天皇とされておるぞ。

**K4** キャラ: 磐井ゴースト
- 問題: 筑紫国造の磐井が、ヤマト政権に対して大きな反乱を起こしたのは、何年じゃ？
- 正解: **527年**
- 誤り: 391年 / 478年 / 645年
- 解説: 527年、筑紫国造の磐井が新羅と結んでヤマト政権に反乱を起こしたが、翌年までに鎮圧されたのじゃ。

## 要確認（年や表現が揺れる項目）

| 項目 | 揺れの内容 | 下書きでの扱い |
|---|---|---|
| 邪馬台国の遣魏（Y3） | 『魏志』倭人伝は「景初2年」（238年）とも読め、239年（景初3年）とする説が教科書では一般的 | 239年を採用 |
| 好太王碑文（K1） | 「391年（辛卯年）に倭が海を渡って来た」という読み方は一般的だが、碑文の解釈には議論がある | 391年を採用。「出兵した」と表現 |
| 弥生時代の始まり・稲作の伝来 | 従来の紀元前4世紀ごろ説に対し、近年は紀元前10世紀ごろ説もあり年代が定まっていない | 年号の問題にしない（Y4 は遺跡の問題） |
| 古墳時代の始まり | 3世紀後半ごろ（箸墓古墳など）とする説明が一般的 | 解説文でのみ「3世紀後半ごろ」と記載 |
| 「倭の五王」の比定（K3） | 武＝雄略天皇はほぼ通説だが、他の王の比定には諸説あり | 武＝雄略天皇のみ記載 |
| 磐井の乱（K4） | 『日本書紀』の継体21年＝527年に基づく | 527年を採用 |
| キャラ名・語尾 | 「〜じゃ」のコミカル口調は私の案 | 変更可 |

## 確認のお願い

- 各問題の正解・誤りの選択肢・解説に、間違いや言い過ぎがないか
- 「誤り」の選択肢が、実は別の問題では正解になりうるもの（紛らわしすぎるもの）になっていないか
- 難関高校の対策として、足りない重要年号（例: 磐井の乱以外の6世紀の出来事など）の追加希望
